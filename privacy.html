Privacy policy

Open Calculation Platform (OCP), for Windows and Android. Last updated: 22 November 2026.

In short

OCP has no account, no advertising, no analytics and no tracking. Your worksheets stay on your device. OCP goes online only when you open its directory or publish to it.

What stays on your device

  • Your worksheets, components, tables, Python functions and settings are stored on your device, in the files and folders you choose and in OCP's own folder.
  • OCP keeps an automatic copy of an unsaved worksheet on your device, to recover it after a crash.
  • Files you open, save or share go only where you choose (the system's file picker or share sheet).

When OCP uses the internet

  • Directory: when you open the directory, OCP downloads its list, and when you install an item, that item's file. These come from GitHub (raw.githubusercontent.com). GitHub receives the request like any web request, including your IP address; see GitHub's privacy statement.
  • Publishing (optional): when you choose Publish, you sign in to GitHub on GitHub's own page with a code. OCP then sends the component or table you chose, its title, category and description, and your GitHub user name to the public directory as a pull request. It becomes public. The sign-in is kept in memory only and forgotten when OCP closes. OCP never sees your GitHub password.
  • Nothing else is sent. OCP does not send your worksheets, your files or any usage information anywhere.
  • OCP shows worksheets with the system's web view (Microsoft Edge WebView2 on Windows, Android System WebView on Android). These components are Microsoft's and Google's and follow your system's own diagnostic-data settings; OCP loads nothing from the web through them.

Python functions (Windows)

Python functions you bring in run in the Python installed on your computer. What they do is up to their code; OCP warns before you bring one in.

Permissions (Android)

  • Internet: only for the directory and publishing, as above.
  • OCP asks for no other permission. Files are opened and saved through the system's file picker, which gives OCP access only to the file you pick.

Children

OCP is a tool for engineering calculations and does not collect personal information from anyone, including children.

Changes and contact

If this policy changes, the new version is published on this page with its date. Questions: open an issue.
