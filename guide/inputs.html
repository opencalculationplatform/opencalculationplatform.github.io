Drop-downs, sliders and check boxes

Select a definition, then choose one of these on the Insert tab (or in the formula's right-click menu):

  • Drop-down list: the value is picked from a list, such as Material := "S275" from S235, S275, S355. In the list dialog, Show as also offers radio buttons or a list box.
  • Slider: drag to set a value, such as t := 12 mm between limits and in steps you choose.
  • Check box: ticked it is 1, else 0, for an if in the formulas below.

The control writes the value just as typing would, so every formula below follows.

Tables

Insert › Table adds an editable grid. Give it a name and its numbers become a matrix you can use in formulas. Texts are allowed too, for a list of sections with vlookup.

Insert › Input table: each column is a variable with a name, a unit and one value or several. A tidy way to enter loads or a set of cases.

For section catalogues and material properties, the lookup tables are easier: IPE("IPE 300", "A").

Data from files

Read data from a file in the worksheet's folder:

READEXCEL("loads.xlsx", "Sheet1!A2:C20")a range of an Excel workbook
READCSV("measurements.csv")a CSV file
READPRN("data.prn")a text file of numbers

Numbers and texts come in as a table (a matrix). When the file changes, the worksheet calculates again. For safety, only files in or under the worksheet's folder are read, never network or internet paths.

Excel inside a worksheet Pro

Insert › Excel › From file keeps a workbook inside the worksheet; New sheet starts an empty one. Click a cell to make it an input (it gets a worksheet value) or an output (it defines a name). OCP calculates the workbook's formulas itself, and Open in Excel edits it in Excel.

Other worksheets

Insert › Include worksheet writes include("file"): the definitions of another worksheet, from this worksheet's folder, are available here. When that worksheet changes, this one calculates again. Includes can be nested.

Python scripts

Insert › Python script adds a script region. Its # in: line names the values it reads (with units), its # out: line the names it defines for the formulas below:

# in: L [m], w [kN/m]
# out: M [kN*m]
M = w * L**2 / 8

Scripts run in the Python installed on this computer, and only when you turn on Calculus › Run scripts for that worksheet. It is off whenever a worksheet opens. Turn it on only for worksheets you trust: a script can do anything Python can. For functions you call from formulas, see Python functions.
