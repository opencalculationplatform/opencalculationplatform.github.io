Reports, and opening Mathcad files

Turn a worksheet into a PDF or Word report, show the values in each formula for checking, and open Mathcad Prime files.

On this pagePDF reportsWord reports ProContents and numbered headings ProValues in formulasResult formatOpening Mathcad Prime (.mcdx) files

PDF reports

Report › PDF (or File › Export PDF) prints the worksheet as it looks, with a page footer. Fill in Report › Report details (project, title, engineer and the other title block fields) and turn on Header to start the report with a title block and a summary. Errors are always stated.

Word reports Pro

Report › Word writes a Word document with the formulas as real Word equations, the plots as pictures and the text as Word text, ready to edit.

Contents and numbered headings Pro

  • Contents: a table of contents of the Heading 1 and Heading 2 texts after the header. In PDF the entries are links; in Word it is a real table of contents with page numbers, filled in when Word updates fields.
  • Number headings: 1, 1.1, 1.2, 2… A text can refer to a heading as [[Loads]], and the report writes “section 2.1”.

Values in formulas

Format › Values in formulas shows each result with the values put in, for checking by hand: . On the page and in PDF and Word reports.

Result format

Format › Results sets the number format (significant digits, general, decimal, scientific or engineering), the digits or decimal places, and whether to show trailing zeros. The format you chose last is what a new worksheet starts with. On the phone: ⋮ › Format and page.

Opening Mathcad Prime (.mcdx) files

  • Open a .mcdx file like any worksheet: formulas, text, units, plots, matrices, range variables, complex numbers, global definitions, highlights, right-to-left text and symbolic keywords come across as OCP regions.
  • What OCP cannot read is kept read-only rather than lost, and the Problems panel says so.
