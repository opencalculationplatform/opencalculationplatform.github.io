Components, tables, Python and the directory

Make OCP yours without programming: reusable components, tables as functions, Python functions, and an open directory to share them.

On this pageComponentsLookup tablesPython functionsThe directoryPlugins for developers

Components

A component is a worksheet you can insert into any other, with a form for its inputs and a report of every step.

Make one

  1. Write the calculation with example values.
  2. Choose Insert › Save as component (phone: ⋮ › Save as component…).
  3. Give it a title, a category and a short description of what it calculates and its limits.
  4. For each name, choose Input, Result or neither, and give it a label. The first result is the component's value for the formulas below it.
  5. Keep the worked example option on: OCP calculates its examples again each time the component is saved or added, and says if an answer changed.

Use one

Insert › Components lists yours by category. Its form takes values (3 m) or names from the worksheet. Show the calculation opens the report: inputs in the units you typed, each step as written math, and the results.

Components can use other components. Share one with Show file (Windows) or ⋮ › Share (phone): it is a single .ocpc file.

Lookup tables

A table becomes a function every worksheet can call, by its name, a row and a column. Columns keep their units.

Pick a row from a drop-down

In Insert › Tables, choose Insert drop-down (phone: tap the table). The drop-down defines the row, and every formula below follows when you pick another.

Bring in your own

  • A CSV file (;, , or tab) or an Excel workbook (.xlsx, its active sheet).
  • A heading row: the key column's heading, then each column with its unit in brackets, A [cm^2] or A (cm²). Then one row per key. Decimal commas work, and a title above the heading row is left out.
  • The table takes the file's name: IPE sections.xlsx becomes IPE_sections.
Section;h [mm];A [cm^2];Iy [cm^4]
IPE 200;200;28.5;1943
IPE 300;300;53.8;8356

View (phone: the table icon) shows every row and column. Rows are found ignoring spaces and case ("ipe300" works); columns ignoring case, so two columns cannot be called Iy and iy.

Python functions

For what a formula cannot say easily (loops, iterations, a code procedure), write a function in Python and call it from any formula. Windows, with Python 3 installed.

import math

def moment(w: "kN/m", L: "m") -> "kN*m":
    '''Mid-span bending moment of a simply supported beam.'''
    return w * L**2 / 8

def deflection(w: "kN/m", L: "m", E: "GPa" = 210, I: "cm^4" = 8356) -> "mm":
    return 5 * w * (L * 1000) ** 4 / (384 * E * 1000 * I * 1e4)

Then in a worksheet: moment(10 kN/m, 6 m) = 45 kN·m and deflection(10 kN/m, 6 m) = 9.617 mm.

  • The unit in quotes is the unit the number arrives in: moment(10000 N/m, 600 cm) still gets 10 and 6.
  • The unit after -> is the result's. Without one, the result is a plain number or a text.
  • A parameter without a unit gets SI base units, a text, or a list for a vector or matrix. A parameter with a default can be left out.
  • Functions whose name starts with an underscore are left out.

Insert › Python functions: New from example starts a file like the one above; Read again picks up your edits; Insert call writes a call. Bring in only files you wrote or trust: a Python function can do what Python can, and OCP warns before it brings one in.

The directory

The directory lists components and tables shared by OCP users: steel sections, materials, beam, column, footing and concrete checks.

  • Install: Insert › Directory (phone: ⋮ › Directory), search, Install. OCP checks each download against its size and fingerprint before adding it. Update appears when a newer version is listed.
  • Publish: in Components or Tables, select yours and choose Publish (phone: its ⋮ › Publish). The first time, OCP shows a code to enter on github.com (a free account; OCP never sees your password). Your item is sent for review and, once accepted, everyone can install it.
  • A component is published only if its worked examples pass and it has a category and a description.
  • Nothing installed from the directory runs code: components are worksheets, tables are data.

Plugins for developers

Developers can extend OCP in C#: new functions (with units, descriptions and categories), new calculation sections, components with their own forms and reports. File › Plugin Manager installs, enables, disables and sets up plugins. The plugin SDK and its documentation are coming with the open-source engine.
