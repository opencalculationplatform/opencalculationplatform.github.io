Operators and definitions

Definitions

:=
Definition: name := expression (type : then =)
≡
Global definition: name ≡ expression holds everywhere in the worksheet, above it too (type ~)
=
Evaluation: expression = shows the result
f(x) :=
Define a function of one variable
m..n
Range variable: i := 0..10 takes each value in turn, and a formula using i is worked out for each (type ..)

Operators

+
Addition
−
Subtraction
·
Multiplication (type *)
a/b
Fraction (type /)
xⁿ
Power (type ^)
x₁
Subscript, part of a name (type _)
√
Square root (type sqrt)
ⁿ√
Root of any order
( )
Parentheses
|x|
Absolute value

Numbers

Arithmetic

sqrt
Square root
abs
Absolute value
min
Smallest of its arguments (any number, same units)
max
Largest of its arguments (any number, same units)
floor
Rounds a plain number down: floor(9.8) = 9. To use a length, divide it by its unit first
ceil
Rounds a plain number up: ceil(9.2) = 10
trunc
Drops the decimals of a plain number: trunc(-9.8) = -9
round
Rounds a plain number to the nearest whole number
mod
Remainder of the first argument divided by the second
sign
Sign: 1, 0 or −1 (of a value with any unit)
gcd
Greatest common divisor of whole numbers
lcm
Least common multiple of whole numbers

Constants

π
π = 3.14159…, built in
i
The imaginary unit: write 3+4i or 3+4j (a number before i or j; i alone is a name)
e
Euler's number e = 2.71828…, inserted as exp(1): OCP has no built-in e, so e stays free for your own variables
g
Standard gravity, inserted as the value 9.80665 m/s² (or write 1 g; the gram is gm)

atan
Inverse tangent, in radians

csc

Complex numbers

Im
Imaginary part of a complex number

conj

Statistics and lookup

Statistics

rnd
A random number from 0 up to x, in x's unit; it stays the same until the line is edited (or SEED := 2 changes every line's)
runif
runif(m, a, b): m random numbers spread evenly from a to b
rnorm
rnorm(m, μ, σ): m random numbers of a normal distribution, mean μ and standard deviation σ
mean
Average of all the values (vectors, matrices, any number of them)
median
Middle value of all the values
stdev
Standard deviation of a population; Stdev for a sample
Stdev
Standard deviation of a sample (divides by n − 1)
var
Variance of a population; Var for a sample

Lookup

match
Where a value is in a vector, counting from 0 (all the places it is)
lookup
lookup(z, A, B): what B holds where A holds z
vlookup
vlookup(z, table, column): the column’s values in the rows whose first column is z
hlookup
hlookup(z, table, row): the row’s values in the columns whose first row is z

Matrices

Matrices

M[i]
An element: v[i] or M[row, column], counting from 0
Mᵀ
Transpose: rows become columns
→
Vectorize: the expression under the arrow works element by element
M⁻¹
Inverse of a square matrix whose elements share one unit (after the matrix)
det
Determinant of a square matrix
rows
Number of rows
cols
Number of columns
length
Number of elements of a vector
last
Index of the last element of a vector, counting from 0
matrow
One row of a matrix, counting from 0
matcol
One column of a matrix, counting from 0
identity
The n × n identity matrix
augment
Matrices side by side (the same number of rows)
stack
Matrices one above the other (the same number of columns)
submatrix
Part of a matrix: submatrix(M, first row, last row, first column, last column), counting from 0
diag
A square matrix with a vector on its diagonal
tr
Trace: the sum of a square matrix’s diagonal
rank
Number of independent rows of a matrix
norme
Length of a vector (Euclidean norm), or of all a matrix’s elements
cross
Cross product of two vectors of 3 elements
sort
A vector sorted from smallest to largest
csort
The rows of a matrix sorted by one column, counting from 0
reverse
A vector’s elements, or a matrix’s rows, in reverse order

Calculus

Calculus

Σ
Finite sum: index = first value, last value at the top, then the term
∫
Definite integral, evaluated numerically: lower and upper bound, integrand, then the variable after d
d/dx
Derivative: with = its slope at the variable’s value above; with → its formula (Ctrl+.)
lim
Limit, with →: lim x→0 sin(x)/x → 1; x→∞ for infinity
∫ dx
Integral without limits, with →: its formula (an antiderivative)

Symbolic (→)

Symbolic

→
Symbolic evaluation: the expression simplified, names without a plain value kept as symbols (Ctrl+.)
expand
Multiplies out products and powers of sums, with →: expand((x + 1)^2) → x² + 2x + 1
factor
Takes out common factors, with →: factor(6x² + 3x) → 3x·(2x + 1)
solve
Solves an equation for a name, with →: solve(a·x + b = 0, x) → −b/a; up to x³. Several linear equations together: solve([x + y = 3; x − y = 1], [x; y]) → [2; 1]
substitute
Puts a value in for a name, with →: substitute(a·x², x = 2) → 4·a
series
Taylor series, with →: series(f, x, n) gives the terms up to x^(n−1) about 0; series(f, x = a, n) about a
collect
Gathers the powers of a name, with →: collect(a·x + b·x + c, x) → (a + b)·x + c
parfrac
Partial fractions, with →: parfrac(1/(x² − 1), x) → 1/2/(x − 1) − 1/2/(x + 1); denominators up to x³ with real roots
assume
Works out with the sign of a name given, with →: assume(√(x²), x < 0) → −x; |x| opens by its sign
float
Works out a → result as a number of so many digits: float(√2, 4) → 1.414

Solving and fitting

Solving

root
A root of an expression in a variable within an interval where it changes sign: root(f(x), x, a, b); root(f(x), x) starts from x's value above
minimize
Where an expression is smallest in a variable, within an interval: minimize(f(x), x, a, b); or near x's value above: minimize(f(x), x)
maximize
Where an expression is largest in a variable, within an interval: maximize(f(x), x, a, b); or near x's value above
lsolve
The solution x of the linear system A·x = b: lsolve(A, b), with units (x in b's unit over A's)
eigenvals
The eigenvalues of a symmetric matrix, smallest first (e.g. principal stresses, natural frequencies²)
eigenvecs
The eigenvectors of a symmetric matrix as columns of unit length, in the order of eigenvals
polyroots
The real roots of a polynomial from its coefficients, the constant first: polyroots([−6; 11; −6; 1]) gives 1, 2, 3

Curve fitting

line
The least-squares line through points: line(vx, vy) gives its intercept and slope
slope
The slope of the least-squares line through points (vx, vy), e.g. a stiffness from test data
intercept
Where the least-squares line through points (vx, vy) crosses x = 0
polyfit
The least-squares polynomial of degree n through points: polyfit(vx, vy, n) gives its coefficients, the constant first
linterp
Linear interpolation in a table: linterp(vx, vy, x), the x values increasing
interp
Smooth interpolation by a natural cubic spline: interp(lspline(vx, vy), vx, vy, x)

Comparisons, logic and programming

Comparisons

<
Less than: gives 1 (true) or 0 (false)
≤
Less than or equal (type <=)
>
Greater than
≥
Greater than or equal (type >=)
==
Equal, within a relative tolerance of 1e-12
≠
Not equal (type !=)

Logic

∧
And: 1 when both sides hold, otherwise 0
∨
Or: 1 when either side holds, otherwise 0
¬
Not: 1 when the condition does not hold, otherwise 0

Programming

if
Condition: the first value when the condition holds, otherwise the second
else if
Condition with two tests: the value of the first condition that holds, otherwise the last value
for
Loop: the lines below it, behind its bar, run for each value of the name, from the first to the last. Write it after v :=, or on a line of a program. Enter adds a line; ← (type <-) sets a name, as v[i] ← i^2. The last line is the result
while
Loop: the lines below it, behind its bar, run again while the condition holds. Enter adds a line
←
Set a name inside a program, as a ← 2 or v[i] ← i^2 (type <-)
