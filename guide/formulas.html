OCP Guide

Formulas

Define values and functions, show results, use ranges and conditions. OCP reads a worksheet from top to bottom and left to right, like a calculation on paper.

On this pageDefine and evaluateNamesGlobal definitionsYour own functionsRangesConditions and checksProgramsHow OCP calculates

Define and evaluate

:= gives a name a value; = shows a value. A definition can show its result too: end it with =.

OCP reads the worksheet like a page: a name must be defined above (or to the left of) where it is used. Move a formula by dragging its border.

Names

Names start with a letter and may use letters, digits, Greek letters and a subscript: type _ for . Type a Greek letter by its name (alpha, sigma, gamma) or pick it from Math › Greek. Upper and lower case are different names.

Global definitions

≡ (type ~) defines a name for the whole worksheet, above it too. Use it for constants you keep at the end of a sheet.

Your own functions

Define a function with its parameters in brackets, then call it with any values, with or without units.

Ranges

A range variable takes each value in turn: i := 1..5. A formula that uses it is worked out for each value and shows them all. Give a second value to set the step: x := 0 m, 1 m..4 m.

Ranges also drive plots and element definitions such as v[i] := i².

Conditions and checks

A comparison is 1 when true and 0 when false, ready for a pass/fail check.

Comparisons

<
Less than: gives 1 (true) or 0 (false)
≤
Less than or equal (type <=)
>
Greater than
≥
Greater than or equal (type >=)
==
Equal, within a relative tolerance of 1e-12
≠
Not equal (type !=)

Logic

∧
And: 1 when both sides hold, otherwise 0
∨
Or: 1 when either side holds, otherwise 0
¬
Not: 1 when the condition does not hold, otherwise 0

Programs

For decisions and loops, use the Programming group (Calculus tab): if, else if, for, while and local definitions (←). A program is a single formula whose last line is its value.

Programming

if
Condition: the first value when the condition holds, otherwise the second
else if
Condition with two tests: the value of the first condition that holds, otherwise the last value
for
Loop: the lines below it, behind its bar, run for each value of the name, from the first to the last. Write it after v :=, or on a line of a program. Enter adds a line; ← (type <-) sets a name, as v[i] ← i^2. The last line is the result
while
Loop: the lines below it, behind its bar, run again while the condition holds. Enter adds a line
←
Set a name inside a program, as a ← 2 or v[i] ← i^2 (type <-)

How OCP calculates

  • Automatic (Calculus › Calculation): results update after every change. Turn it off for heavy worksheets and press F9 or Calculate when ready.
  • Disable (Ctrl+E, or the formula's menu): keep a formula, plot, solver or section on the page without calculating it. Press again to enable it.
  • Problems panel: every error and warning, with a click to go to it. Errors always show on the page; View › Warnings on page shows or hides the yellow warnings.
  • When a region grows (a result, a plot), the regions below it move down so nothing overlaps.
